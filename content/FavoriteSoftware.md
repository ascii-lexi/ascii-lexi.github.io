title: My Favorite FOSS
date: 2026-07-20
summary: It's FOSS!

I will be updating this page as I try new software.

## Editors
- **Ghostwriter** - a WYSIWYG markdown editor that I have used to write every article for this blog! Has spellcheck which is something I find incredibly useful as a dyslexic.

- **NeoVim** - no explanation needed. I use it for config files mainly, not as a terminal IDE. I am not what the kids call a *[NVChad.](https://nvchad.com/)*

- **LibreOffice Suite** - Great for editing .docx without paying the devil his due, I used it recently for making my resume a docx document so the *AI Joblords* can read it better. (btw if you have strange scaling in LibreOffice on Wayland on a 4k monitor: check out this helpful blog [post](https://blog.aether.us/2025/10/13/libreoffice-scaling/) from CodeMonkey, a stylish blog haver).

- **Krita** - Technically for digital artistry like painting, but I use it as a Photoshop replacement as it has very similar keybinds, I can mask, I can clone stamp, I can edit color curves. It is Photoshop shaped and not *GIMP*.

- **DaVinci Resolve** - I used it a lot on Microslop Windows, but thinking of migrating away from it to **KdenLive** or something as it only supports a few video codecs on Linux.


## Media
- **Tambourine** - aesthetically pleasing music player, but bare bones, now looking for software with playlist capability.

- **VLC** - Traffic Cone. Use it for watching DVDs/BluRays on Linux.

-  **Blender & Godot** - 3D editing and game engine when I feel like making something interactive.

-  **Foliate** - Epub reader, no frills but less heavy than Calibre

-  **❤️ LocalSend ❤️** - LAN file transfer that is perfect in every way. Solves a very common issue and has good enough UX for non-technical people to use it and easily identify why it is useful.


## Development
- **TrueNAS** - Technically partially FOSS, which is the part I use. Allows me to get a good web UI overview of my media server which runs some development containers as well. Blog post on this server coming soon!

-  **Code - OSS** - FOSS VS Code. I really, really, *really* gave Kate a shot but it is painful to get simple features like debugging to work.

-   **Termux** - Terminal multiplexer, great for multitasking on ssh and slow operations you don't want to have to `ps aux | grep "long ass rsync job"` or search for in `top`.


### Not FOSS shameful mention
-   **TailScale** - not foss, I haven't tried Pangolin yet. It makes the internet *feel* like a [series of tubes](https://www.youtube.com/watch?v=_cZC67wXUTs), and not 20 NAT tables talking to each other. (IPv4 be damned)
