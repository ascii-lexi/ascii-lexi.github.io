My Favorite FOSS

I will be updating this page as I try new software.

Editors

  • Ghostwriter - a WYSIWYG markdown editor that I have used to write every article for this blog! Has spellcheck which is something I find incredibly useful as a dyslexic.
  • NeoVim - no explanation needed. I use it for config files mainly, not as a terminal IDE. I am not what the kids call a
  • LibreOffice Suite - Great for editing .docx without paying the devil his due, I used it recently for making my resume a docx document so the AI Joblords can read it better. (btw if you have strange scaling in LibreOffice on Wayland on a 4k monitor: check out this helpful blog from CodeMonkey, a stylish blog haver)
  • Krita - Technically for digital artistry like painting, but I use it as a Photoshop replacement as it has very similar keybinds, I can mask, I can clone stamp, I can edit color curves. It is Photoshop shaped and not GIMP.
  • DaVinci Resolve - I used it a lot on Microslop Windows, but thinking of migrating away from it to KDenLive or something as it only supports a few video codecs on Linux.

Media

  • Tambourine - aesthetically pleasing music player, but bare bones, now looking for software with playlist capability.
  • VLC - Traffic Cone
