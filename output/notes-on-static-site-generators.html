Notes on Static Site Generators

The short version

If you already know Python, Pelican's templates will feel familiar. If you want a single fast binary, Zola is great. If you want full control over every line of HTML, write your own — it's less work than it sounds.

Trade-offs

The templating language is rarely the hard part. Getting the CSS to feel intentional is.

That's the part this project tries to solve up front, so you only have to tune six variables instead of designing a theme from scratch.
